# Samples

One console project for each feature of PinkRooster.NugetPublisherMcp. Run any sample with `dotnet run --project samples/<name>`. Each sample has a `RunAsync` that a test in `tests/PinkRooster.NugetPublisherMcp.Samples.Tests` runs, and none needs a secret.
